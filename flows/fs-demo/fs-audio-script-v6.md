## The Demo

The Flowsmithy run screen remembers what happened last time.
This was a while ago so the results are marked by the left icons as stale.

* let's kick off a new one.
* We hit *Run Task* to run again
* This run hit a snag and the run screen reacts
* The task is flagged as **FAILed**
* A remedial step becomes **visible**
* The dependant task is **blocked**

We run the remediation step

* The initial task state is updated
* Now we run it again - the blue status line shows progress [takes 5 secs so we pause]
* We get new results
* We can now run the publish step
* Publish Results carries the same computer name, cycle,
and event into its own Brief panel — and the log backs that up too.
